# 独立定制绘图插件

**v0.3.1 · 2026-10-27 H28K 当前源码快照**

本仓库当前目录已完整替换为 H28K 实际使用的独立插件及配套后端。旧小白定制快照、补丁集合、原版手动界面和旧安装说明不再混入当前版本；旧版本保留在 Git 历史中供回退。

## 当前功能

- 剧情直出：聊天回复提供图片描述、人物资料和原文定位句，插件直接调用 ComfyUI，不再另走场景规划。
- 人物库、姓名与别名匹配、参考照片、角色分组、绘图世界书、正负向固定提示词。
- 服装与持续状态继承，按实际剧情更新对应角色。
- 多张图片插入各自对应的正文位置，支持单图重绘、图库、错误日志和刷新后恢复。
- 角色卡使用中文资料；生成绘图提示词时由酒馆当前模型理解并转换，不依赖已删除的独立翻译接口。
- 同步角色保存的草稿判断，移除旧英文编辑、翻译和标签库相关内容。
- 同步悬浮窗、取消、页面恢复及任务记录读写修复。聊天图位保存未确认、实际未提交绘图时，明确报错并结束等待，不再一直显示“确认”。图位和正负向提示词保留。
- 已受理但回执丢失的任务继续按原任务编号接回，避免重复提交。

前端最低版本声明为酒馆1.13.0；实际部署验证使用酒馆1.19.0、Node.js 24。新版安装建议使用当前酒馆及Node.js 20以上。ComfyUI模型和自定义节点需要使用者自行准备，本仓库不会下载模型。

## 安装

1. 在酒馆的扩展管理中使用本仓库地址安装前端：`https://github.com/Mr47Forge/SillyTavern-Image`。
2. 等待已有任务完成并保存结果，再停止酒馆并备份原后端。在插件的安装指引中下载匹配的压缩包，或下载本仓库的 `server-plugin/sillytavern-image-server.zip`。解压后，将其中整个 `sillytavern-image-server` 文件夹放入酒馆的 `plugins` 目录。也可直接使用仓库的 `server-plugin` 源码目录。
3. 更新旧后端时，先将整个旧文件夹移到备份目录，再放入新文件夹，避免直接合并后残留旧文件。
4. 酒馆配置需启用服务端插件。重新启动酒馆，然后刷新网页。
5. 打开独立绘图设置，核对 ComfyUI 地址、工作流、角色照片和出图尺寸，再使用安全的简单场景测试。

也可使用安装辅助脚本：`node scripts/install-server.mjs 酒馆安装目录`。脚本会完整备份原后端并安装当前后端，不修改用户设置，也不自动重启酒馆。

前后端必须来自同一版本。这里的 `server-plugin/runtime` 使用自己的内部协议版本，其编号不等于插件产品版本，请不要单独混装。

## 当前设置快照

`settings/` 包含2026-10-27导出的两份有效绘图设置：正负向提示词、预设、工作流、角色、分组和绘图世界书。**局域网 ComfyUI 地址按用户要求保留**；本次未发现已填写的密钥，也没有导出已废弃的独立模型配置。导出没有修改 H28K 设置。

使用快照前先停止酒馆，并备份目标用户的原文件，再将两份 JSON 放入酒馆 `data/用户目录/user/files/`，保留原文件名。重新启动并刷新后核对设置。具体说明见 [设置说明](settings/README.md)。这是用户主动恢复步骤，安装插件不会自动覆盖已有设置。

角色照片、聊天、历史图片、账号、模型及缓存属于运行数据，不包含在公开代码中。设置里的原有照片引用保留；在原H28K环境继续使用已有照片，新环境需要重新准备照片。

## 验证

开发检查使用 `npm run check`、`python scripts/build-server-package.py --check` 和 `npm test`。修改后端编译源码后，先运行 `npm run build`，再运行 `python scripts/build-server-package.py` 更新下载包。开发检查需要 Node.js 和 Python 3；普通用户安装不需要开发依赖。

- 发布检查核对前后端依赖、界面资源、设置格式、后端运行包及下载压缩包与源码一致性。
- 最新“确认”修复已完成相关测试及手机尺寸隔离页面验收，覆盖未提交失败、保留提示词、已受理任务接回和避免重复提交。隔离验收不代表已重新执行真实出图。
- 换装回归使用两位女性角色，覆盖代词、多人变装及持续状态归属，保留原来的全部判断；男性过滤规则有独立回归检查。运行逻辑没有因测试资料调整而改变。
- 本次发布未重新调用真实聊天模型或 GPU。旧版本的真实出图验证不能代替本次版本验证，不能据此宣称所有预设和遗留场景已经通过。

后台保留现网仍存在的历史任务兼容代码，本次发布没有进一步改动它们。

## 目录

| 目录 | 内容 |
| --- | --- |
