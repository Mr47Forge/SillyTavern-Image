# SillyTavern-Image

独立的酒馆定制绘图扩展。**v0.2.0 已把小白X定制版的 ComfyUI 绘图模块及必要兼容能力迁入独立版**；运行时不要求安装小白X，以后绘图定制在本仓库维护。

## 当前功能

- 剧情场景规划、角色姓名与别名匹配、角色库及参考照片、角色分组。
- 自动或手动触发绘图、楼层插图、图库和大图查看、单图重新规划及提示词重绘。
- 独立后台任务、取消、失败诊断和刷新后的任务恢复。
- 独立设置、数据库、事件与后台接口；兼容旧聊天插图记录和旧角色照片路径。
- 可明确复制当前用户的小白X绘图设置、角色库、规划模型设置及当前浏览器的旧图库。复制前备份独立配置，保留原始数据；不接管旧插件的活跃任务。
- 小白X绘图仍开启时阻止独立版启动，避免两边重复绘图。小白X其他功能可保留。
- 保留 v0.1 手动面板，供原有操作继续使用。

内置可选 Krea2 锁脸预设固定为 **力度4、细节1024、对齐、8步、768×1152**，使用现有 SageAttention 节点。照片缺失时明确提示补齐；旧的纯文生图预设仍按原逻辑运行。多人参考不代表已保证多人身份完全一致。

## 安装和旧数据迁入

1. 在酒馆扩展管理中通过本仓库地址安装前端，根目录 `manifest.json` 加载 `extension/entry.js`。
2. 将本仓库 `server-plugin/` 复制到酒馆安装目录下 `plugins/sillytavern-image-server/`。可使用 `scripts/install-server.sh`，会备份已存在的同名插件，不自动重启酒馆。
3. 酒馆配置需允许服务端插件，安装后由操作者安排重启。普通使用不需要安装本仓库的开发依赖。
4. 等待原绘图任务结束，在小白X中关闭绘图功能，然后打开“独立绘图”。需要旧设置时点击“从小白X复制绘图配置和本机图库”，完成后刷新页面。
5. 核对绘图服务地址、规划模型和角色照片，再选择已有工作流或“使用已测试的8步锁脸预设”。新预设要求现有 Krea2 模型及 Krea2EditModelPatch、Krea2EditGroundedEncode、PathchSageAttentionKJ 节点，不会自动下载模型。

再次复制配置会先备份当时的独立设置，再导入旧设置。旧图库只补充缺失记录。浏览器图库按当前浏览器复制，请在持有原图库的浏览器执行；不要在共享浏览器中混用账户。

**2026-10-24 已在 H28K 酒馆 1.19.0 实际部署验收。** 已跑通角色参考图上传、单人测试、真实 ComfyUI 生成、结果取回和图库保存；力度4、1024、对齐、8步的一次执行约37.4秒，不是稳定平均速度。剧情规划模型、多人效果与断网中途恢复仍需独立验证，详见 `docs/h28k-deployment-20261024.md`。

## 开发与验证

需要 Node.js 20 以上；完整开发检查使用 Node.js 24，浏览器检查使用本机 Chrome，后台 TLS 测试使用 OpenSSL。运行时复用已打包的依赖，普通安装无需执行下列开发命令。

```bash
npm ci
npm test
npm run check
npm run test:browser
```

`npm run build` 生成独立后台绘图运行包，`npm run check` 检查其与前端编译源码一致。浏览器验证采用独立临时用户目录和模拟生图服务，不调用真实显卡或模型。

| 目录 | 用途 |
| --- | --- |
| `extension/` | 独立入口、兼容导入、原版手动面板 |
| `runtime/` | 迁入的定制前端绘图模块和必要依赖 |
| `server-plugin/` | 独立后台、任务持久化、照片读取、工作流 |
| `scripts/` | 构建、检查、隔离浏览器验证、安装辅助 |
| `metadata/standalone-runtime-sources.json` | 原始基线和迁入文件摘要 |
| `custom-files/`、`patches/` | 历史定制快照，保留用于追溯 |
| `docs/standalone-migration-20261023.md` | 本次迁移范围、验证与边界 |

## 历史定制记录

以下记录描述迁入前的小白X版本，不表示本次已部署到实际酒馆。

### 小白 X 人物参考占位符修复（2026-10-14）

此前部分生图路径把 __LWB_ROLE_PHOTO__ 原样交给 ComfyUI，导致第 15 号 LoadImage 节点验证失败。现已增加前端二次匹配、后台兜底和提交前检查：有明确匹配照片时继续上传照片并作为 Krea2 参考；没有可匹配照片时删掉无效图片节点，转成纯文生图。**占位符只供小白 X 动态预设使用，不可直接当作 ComfyUI 真实图片文件名。**

修复后的历史代码见 custom-files/littlewhitebox-server/providers/comfyui/role-photo-upload.js 和 patches/ 里的最新补丁。独立版使用自己的 __ST_IMAGE_ROLE__ 占位符，处理方式独立于该修复。


### 2026-10-14：小白 X 图片查看器与诊断日志

- 图片管理的大图查看器提升到设置页面之上，不再被设置弹窗遮挡。
- 支持滚轮和按钮缩放、拖动已放大图片、方向键和左右按钮切换当前版本与邻近图组。
- 原有图库记录新增 promptTrace：正负提示词及 ComfyUI 已编译节点提示词、seed、步骤数等。后台任务恢复尽可能保留元数据。
- 旧图片可查看原先保留的正负提示词，只有更新后生成的图片才可能有完整工作流参数。
- 图片菜单 / 大图查看器增加提示词日志，设置侧栏增加错误日志；最多保留300条错误，独立 IndexedDB 存储。
- 不删除聊天、图库数据或历史工作流，不修改独立版 extension/ 和 server-plugin/。
- 针对性检查及原有相关测试共39项通过；H28K实际浏览器点击尚需验证。另有一项原测试因缺少 fake-indexeddb 测试依赖未运行。


### 2026-10-14：多图位置恢复和图库交互修复

- 最近聊天落盘核对：两张图对应的两个不同 source slotId 均存在。无需修改用户的消息原文或删除既有图片。
- 当 SillyTavern Markdown/HTML 格式化意外遮蔽某个图片标记时，先将图片标记保护成临时纯文本标记，格式化后按原顺序恢复，再逐一投影独立图片卡。若当前消息 DOM 缺少已保存的标记，仅做一次受身份校验保护的恢复；不能恢复时输出可诊断的计数日志，避免无限循环。
- 修复图片管理大图查看器：正常比例也能用鼠标左键拖动；缩放后限制平移范围、正确释放鼠标捕获；底部缩略图、操作栏与状态文字保持在视口下部，不随图片高度挤出浏览器。
- 独立 Chrome 无界面 DOM 测试：两个标记在跨段落与 Markdown 标记消失模拟下，仍恢复为两个独立卡片；桌面和窄窗口的底部栏可见、100%/200% 拖动、复位均通过。
- H28K 原多图/交付回归测试：136 项通过；另 2 个测试因缺少开发测试依赖 linkedom 和 fake-indexeddb 未运行，不能视为功能失败。
- 本次只更新小白 X 自定义代码，不修改原有的聊天持久化记录、ComfyUI 模型及独立版运行插件。实际用户浏览器聊天页面仍建议刷新后观察。
