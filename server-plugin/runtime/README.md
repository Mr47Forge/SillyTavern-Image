# 独立绘图后台运行模块

当前前端由酒馆本轮回复中的绘图块建立图片任务，后台负责 ComfyUI 队列、图片结果、取消和恢复。前端不使用独立场景规划或独立大模型页面。

安装包位于前端扩展 server-plugin/sillytavern-image-server.zip。解压后复制到酒馆 plugins 目录，启用 enableServerPlugins；升级需等现有任务结束，再重启原酒馆服务。

后台任务结果暂存于内存，重启无法续跑尚未保存的结果，因此升级前必须完成结果接回。聊天已保存的图片与用户设置不在安装包内，不应覆盖或删除。

历史供应商适配与部分规划合同仍作为旧任务兼容实现保留，当前前端只建立ComfyUI绘图任务。设置接口使用当前登录用户的文件目录，通过版本条件阻止旧设备覆盖新设置。程序路径、协议版本及功能清单以现有manifest和状态接口为准。

测试只使用临时目录与模拟上游，不包含真实密钥；真实模型和GPU测试须另外授权。
