# 独立绘图后端运行模块

这是当前独立定制绘图插件的配套后端内部模块。完整安装与设置恢复方法见仓库根目录 README，请安装整个 server-plugin，不要单独复制本目录。

当前前端使用剧情直出和 ComfyUI 图片任务。后端仍包含现网保留的旧提供商与历史任务兼容实现，本次发布未擅自删除。旧规划创建接口已停用，当前前端不依赖另一次场景规划。

后端绘图运行包由当前仓库源码生成。运行 npm run build 重建，npm run check 验证一致性。内部协议版本与产品版本分别管理。

更新前先等待任务完成，完整备份旧后端；安装后重启现有酒馆服务。不要将旧目录与新目录合并，也不要运行其他旧插件的设置迁移接口。
