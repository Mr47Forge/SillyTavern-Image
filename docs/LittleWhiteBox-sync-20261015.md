# 2026-10-15 · H28K 小白 X 定制快照

这里保存基于 RT15548/LittleWhiteBox 的定制源码，基线提交为 9e71caef9ba7b3ca324ce9f1cb06a69ff54d734b。

**重要：这里是历史定制备份，不是本仓库独立插件 extension/ 或 server-plugin/ 的运行依赖。** 本次只更新备份文件，没有把小白 X 代码覆盖到独立插件中。

## 更新内容

- 改进当前剧情里的角色姓名与别名匹配，过滤短名误命中，保留角色分组启用状态。
- 单张图片「重新生成」重新规划新提示词，接回悬浮窗的规划、排队、生成、成功/失败进度。
- 保留手动编辑 TAG 的直接重绘逻辑，更新图库记录、图片保存/恢复、提示词和错误诊断。
- 跨设备缺图时展示「拉取这张」「拉取本轮图片」；仅用户主动点击才下载服务器图片。没有服务器保存地址时明确说明无法同步，避免出现手机空白框。
- Scene Planner 单独识别 MODEL_OUTPUT_TRUNCATED，拒绝将未完成的 Tool 调用用于绘图，并阻止同一设置下无意义重试。
- 对 cn:deepseek-v4-flash 绘图场景规划采用低推理强度，日常聊天预设、其他模型和 ComfyUI 绘图工作流保持原状。
- 同步后台 Draw Run、图片任务及日志管理在 H28K 上的定制差异。

## 源文件位置

- patches/LittleWhiteBox-customizations.patch：相对于上游基线的已跟踪源码差异。
- custom-files/LittleWhiteBox/：新增定制模块及相关测试快照。
- patches/littlewhitebox-server-live-customizations.patch：H28K 运行版服务器插件相对源码内插件的差异。
- custom-files/littlewhitebox-server/：运行版额外定制模块和测试。
- metadata/source-sha256.json：定制文件 SHA-256 摘要。
