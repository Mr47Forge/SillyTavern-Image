# 独立版开发进度

## v0.1.0 · GitHub 第一版（当前）

- 独立酒馆扩展及独立 Server Plugin，不依赖小白 X 运行代码。
- 人物照片按当前酒馆用户分别保存，关联当前角色卡。
- Krea2 生成阶段读取角色照片；无照片时纯文本生图。
- 可以手动编辑提示词、读取最新聊天、导入 ComfyUI API 工作流。
- 从 ComfyUI 返回 PNG 并在酒馆界面中预览、保存。
- 已通过模拟 ComfyUI 请求及存储的 Node 测试。

**边界：** 尚未部署到 H28K；尚未在真正的 SillyTavern 浏览器界面验证。

## 下一阶段：H28K 并行安装验证

- 核实根目录 manifest 被 SillyTavern 1.19 正确识别。
- 在原有 LittleWhiteBox 保持运行的情况下并行加载独立插件。
- 核实 ComfyUI 地址/模型列表、角色照片保存、首次生成、二次生成、图片预览与下载。
- 出错时只回滚新独立插件，不修改原有小白 X。
- 验证插件禁用或卸载后，原酒馆功能不受影响。

## v0.2：剧情自动生图

- 从酒馆消息或生成事件获取当前场景与出场角色。
- 把剧情提取与绘图解耦，避免替用户编造动作。
- 自动选择角色照片（准确匹配姓名/别名）。
- 自动生图开关、排队、取消、失败重试与防重复出图。
- 生成图片与对应楼层/聊天记录关联，支持重新生成。
- 工作流操作可观察：等待、采样、取图、已完成或报错。

## v0.3：多人、任务恢复

- 非固定配角与指定固定角色同框两种模式分别处理。
- 2～4 人的图片参考隔离测试，逐渐启用；不承诺天然不串脸。
- 浏览器断线任务可恢复，避免重复提交和重复收费。
- 图库历史与缓存淘汰逻辑。
- 小屏幕适配、完整回归测试。

## 不纳入

小白 X 的变量、总结、记忆、OS 功能，以及与文生图无关的扩展。
