# H28K 实机部署验收（2026-10-24）

## 范围与备份

用户授权在 H28K 的现有酒馆部署独立定制绘图插件。酒馆为1.19.0、ARM64、Node.js 24，扩展和后台分别安装在宿主的扩展与插件持久化目录。部署前保存酒馆配置与用户数据压缩备份，并校验摘要；容器身份保持不变，仅为启用后台及修正目录适配重启酒馆，没有重建容器，未改其他服务器服务。

原角色卡、聊天和密钥等101个文件与备份逐一比较，摘要全部一致。新建一名明确标注的部署测试角色，参考照使用此前AI生成的测试图片，未使用真实聊天做模型测试。没有把真实配置、照片、密钥或会话写入仓库。

## 实机发现与修正

- 酒馆真实图片目录字段为 `userImages`，原测试使用 `images`，导致已登录用户被独立后台误判未登录。统一适配由酒馆认证中间件提供的目录，支持相对数据根目录；不接受请求参数提供目录，也不回退默认用户。
- 单角色测试使用固定提示词时未携带角色身份，导致照片已经上传仍无法匹配。显式传递当前角色，编译时绑定对应照片，不放宽无照片拦截。
- 独立入口与现有“人物档案”按钮重叠，向上移开入口；原扩展保留。
- 补齐规划模型设置界面的两份样式，并增加浏览器样式加载与角色按钮实际出图回归。

## 已验证

- 实际酒馆加载独立前后端；设置可保存，角色与参考图刷新后仍存在。
- 产品版本、完整后台能力、当前用户图片任务与绘图任务恢复列表正常。
- 当前会话、请求校验和后台内部连接校验通过；匿名访问和空任务请求被拒绝。
- 从真实页面点击角色测试，照片通过独立后台传给本机ComfyUI，真实显卡完成生成，图片返回页面并进入独立图库。整页刷新后仍能从图库重新打开大图。
- 实际执行参数：力度4、细节1024、对齐、8步、768×1152。一次执行约37.4秒，包括当次模型准备等服务端工作；不以此宣称稳定平均速度或相似度提高。
- 本机回归曾1401项全部通过；最后一轮1399通过、2项短连接专项出现既有偶发连接重置，未跳过或用重试隐藏。浏览器扩展回归通过，远端检查结果以审查单为准。

## 尚未验证

未调用真实剧情规划模型做自动剧情配图；未进行多人身份质量验收、断网中途恢复、原小白X运行时导入和全部第三方扩展组合测试。此次真实生成走单角色测试及酒馆原生绘图转发，独立后台照片解析和用户隔离已实测，不能据此把完整后台规划与批量恢复也标成实测完成。

ComfyUI由用户明确授权启动，沿用已有Python环境、模型与节点，没有安装或升级模型、节点，没有修改队列配置。测试后保持服务可用，未提交第二个真实生图任务。
