# 独立定制绘图迁移

本文保留初次隔离验证记录；后续已授权的 H28K 实机部署结果见 [实机验收](h28k-deployment-20261024.md)。

用户目标：以后在独立文生图插件维护和使用小白X定制绘图内容，兼容酒馆及其他扩展，不依赖小白X运行。

## 实现约定

- 复用仓库记录的上游基线和两份定制补丁，迁入 ComfyUI 绘图及其实际依赖；不重新实现剧情规划、角色库、图库、单图重绘和后台恢复。
- 独立入口、全局对象、事件、页面样式、设置文件、浏览器数据库和后台接口分别命名。旧照片和聊天插图标记作为明确的数据兼容边界保留。
- 原小白X仍在绘图时，独立版提示关闭旧绘图入口，避免两边自动生成；不禁用小白X其他功能。
- 旧配置通过明确的导入按钮复制到新文件，保留原文件；不复制其他业务设置，不清空历史图库或活跃任务。
- 继续保留 v0.1 手动面板及其接口，迁移到新入口下的兼容入口；新的绘图面板使用定制模块。
- 最新锁脸流程作为可选预设；力度4、1024、对齐、8步。保留原有预设和不带照片的行为边界。
- 仅本地修改和隔离验证；不重启、部署或修改现有酒馆、ComfyUI、队列与用户数据。

## 执行计划

1. 重建定制来源，记录版本、摘要和依赖闭包，保留来源说明。
2. 迁入绘图运行模块，接通酒馆事件、消息工具栏、模型配置及独立后台。
3. 增加原配置复制、旧插件共存保护，以及角色照片按当前登录用户读取。
4. 接入已验证的锁脸工作流，保证浏览器与后台编译使用一致的人物绑定逻辑。
5. 运行原有定制回归、独立接口集成及浏览器交互验证；记录未能覆盖的真实部署项。

## 验收重点

- 原插件全局入口和数据不会被覆盖；独立后台拥有完整任务与恢复接口。
- 场景规划、姓名别名匹配、角色编辑、图库、单图重规划和手动 TAG 重绘均由独立模块实际调用。
- 角色照片不回退到默认用户；取消任务不调用全局中断。
- 再次导入先备份独立配置再覆盖；图库仅补充缺失记录；旧数据保留。
- 无本机地址、凭证、照片和聊天进入代码。

## 兼容适配说明

- 设置、事件、浏览器数据库、全局对象和服务接口独立命名；仅保留必要旧照片与旧插图格式读取，不改写原插件配置。
- 消息显示尊重酒馆及其他扩展已经处理的页面，不再因缺少插图标记而整段重建聊天页面；显式消息更新仍保护插图位置。
- 当前登录用户的照片目录由酒馆传入，禁止回退读取默认用户照片。取消只处理本任务，不全局打断队列。
- 旧配置导入后要求刷新，避免内存中的旧设置覆盖新导入结果；活跃旧任务不迁入。
- 最新锁脸预设需要匹配参考照片；不把缺少照片的锁脸请求悄悄改为随机人物。

## 验证说明

浏览器检查实际加载独立入口和迁入的设置界面，覆盖角色、旧照片路径、工作流选择、小屏宽度及独立后台上传照片、编译参数、提交和取图。使用临时模拟账户、模拟 ComfyUI，不读取真实用户照片，不使用显卡。单元回归涵盖规划、图库、重绘、任务及权限隔离。

Windows 本机的真实短连接测试曾偶发出现连接重置，最小独立 HTTP 示例也能复现；尚不能确定外部拦截或系统原因。保留测试，不通过自动重试掩盖，也不据此改写生产连接逻辑。最终结果以本次验证记录为准，真实服务联调仍未完成。
