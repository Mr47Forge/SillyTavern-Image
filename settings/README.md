# 当前设置快照

这两份文件来自2026-10-27 H28K 实际使用的独立绘图插件。局域网 ComfyUI 地址按用户要求保留。导出过程检查并清空认证字段；本次两份有效设置中没有发现已填写的密钥。导出没有修改 H28K 的原设置。

- `SillyTavernImage_ComfyDraw.json`：当前绘图连接、预设、提示词和工作流等设置。
- `SillyTavernImage_NovelDraw.json`：当前程序沿用此文件名存储共享角色、分组、世界书等设置。名称属于现用存储格式，不表示新增了旧版生图界面；不要自行改名。

没有包含旧 `SillyTavernImage_Assistant.json`。人物辅助功能使用酒馆当前模型；另行配置的旧模型设置不属于本版所需内容。

## 恢复方法

1. 等待当前任务结束，停止酒馆。
2. 找到酒馆数据目录中对应用户的 `user/files` 文件夹。
3. 将原来的同名文件复制到单独备份目录。
4. 将本目录两份 JSON 复制进去，按原文件名替换。
5. 重新启动酒馆并刷新网页，核对连接、预设、人物及世界书。

插件安装不会自动执行此恢复，不会擅自覆盖其他用户设置。照片、模型、聊天及历史图片没有打包；原环境保留已有文件，新环境需要自行准备。
